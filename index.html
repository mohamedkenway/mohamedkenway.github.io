Horror Channel Uploader

Horror Channel Uploader is a personal automation tool that creates short videos on its owner's own computer and uploads them to the owner's own YouTube channel (and, optionally, the owner's own TikTok account). It is not offered to the public and is used only by its developer.

Privacy Policy

Last updated: October 2026

What the app accesses

The app asks for permission to upload videos to the owner's YouTube channel (the YouTube upload permission). It does not read, download, or change any other data in the Google account, such as existing videos, comments, subscriptions, email, or contacts.

What is stored

An authorization token is stored locally on the owner's computer so the app can upload without asking to sign in every time. Videos, scripts and logs are also stored locally. No data is sent to any server operated by the developer, because there is no such server.

Sharing

The app does not sell, share, or transfer user data to anyone. Videos are sent only to YouTube and, if enabled, TikTok, using the owner's own accounts.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions, and the locally stored token can be deleted from the computer.
